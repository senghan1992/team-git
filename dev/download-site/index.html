Git Companion

팀이 하나의 프로젝트를 각자 브랜치로 나눠 작업할 때, 커밋·푸시·병합을 터미널 없이 처리하는 데스크톱 앱입니다.

버전 v__VERSION__ 빌드일 __DATE__ 커밋 __SHA__
Windows 설치 파일 다운로드 (.exe) GitHub Releases 에서 받기

설치 방법

  1. 위 버튼으로 .exe 파일을 내려받습니다.
  2. 파일을 더블클릭해 설치합니다 (기존 버전 위에 바로 설치 가능).
  3. 시작 메뉴의 Git Companion을 실행합니다.

이 페이지는 저장소에 push 할 때마다 자동으로 새로 빌드·갱신됩니다. 설치 파일이 오래된 것 같다면 잠시 후 다시 와서 받으세요.

✓ 기존 버전 위에 덮어 설치해도 설정과 저장소 목록은 그대로 유지됩니다.
